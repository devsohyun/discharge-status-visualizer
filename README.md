## Getting Started

### Dependencies

Install packages in terminal:

```
npm install
```


### Installing / Executing

You need to have python installed in your machine in order to run the python file to request API to Thames Water.  
The json file to test is already prepared in discharge/ directory. So do this only if you want to update the file to latest.

1. Install Python from [here](https://www.python.org/downloads/) in your machine.
2. Install datetime using pip
```
pip install DateTime
```
3. Run 'thames_water_discharge.py' to request api to download json file.
```
python thames_water_discharge.py
```
4. Check dischage/ directory to see whether the latest files are downloaded.
5. Go live index.html
